# Bug spec

- Linked GitHub issue number and URL, when one was filed or supplied
- Report, user impact, affected revision and environment
- Expected behavior and its source
- Observed behavior, conditions, evidence, and reproduction status
- Root-cause evidence, confidence, and remaining unknowns
- Bounded fix requirements with stable [REQ-X] IDs and acceptance criteria
- Regression checks, exclusions, and rated open decisions

Name code symbols in backticks with project-relative paths and link earlier artifacts by relative Markdown links so the project knowledge graph connects them. Record approval separately in approvals.md.
